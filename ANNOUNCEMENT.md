**EDI — Community Mod** is an unofficial build of **EDI (Easy Device Integration)**, the Windows app that syncs game events with interactive devices over a local REST API. It's based on the original **EDI by NoGRo** (<https://github.com/NoGRo/Edi>) and is not affiliated with the original author.

**What's new in this mod**

- Redesigned game launcher with cover-art cards, a clear selected-game highlight, and layout options
- Built-in cover/banner search (SteamGridDB, itch.io, and more) with a crop tool and animated GIF/MP4 covers
- Live funscript preview that shows the playing script in real time, freezes on pause, and reflects intensity
- Settings overhaul: inline info popups, a customizable top bar, persistent window state, and a Dev tab
- More robust device handling — it won't crash when Intiface isn't running, plus Handy / OSR / preview fixes

**Requirements:** Windows 10/11 (x64) + the **.NET 8 Desktop Runtime** and **ASP.NET Core 8 Runtime** (<https://dotnet.microsoft.com/download/dotnet/8.0>).
